# Desi references bank

Every batch session reads this before writing clues, uses a few entries each week, and adds new ones it finds. Arvind adds entries any time: tell a session "add to references: ...", edit this file on github.com, or paste a screenshot.

**Rules**
- One line per entry: **name**, what it is, when it peaked, a source link if there is one, a suggested answer word (3 to 9 letters), `added` date, and `used` dates (puzzle dates where it appeared).
- `verify` means the details came from memory and must be checked against a source before they go into a GK clue. A pop (N) clue may use the name alone.
- Fresh means about the last 12 months. Each run moves older entries down a section. Classics are still good for nostalgia clues, never presented as new. The nostalgia sweet spot is 1990 to 2015.
- Don't use the same entry twice within 4 weeks. Update `used` whenever a puzzle uses it.
- No politics, religion or caste, crime or tragedies, and nothing mean about a group (see `docs/clue-style.md`).
- Last cross-check: 25 Nov 2026, by asking Grok and Google Antigravity and then confirming every item against major outlets.
